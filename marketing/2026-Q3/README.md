## Como usar este diretório

1. **Antes de produzir qualquer conteúdo:** ler [`automacao-conteudo-kanban.md`](./automacao-conteudo-kanban.md) e seguir a estrutura do Kanban.
2. **Antes de escrever qualquer e-mail:** conferir [`sequencia-emails.md`](./sequencia-emails.md) — copy já pronta.
3. **Antes de subir qualquer anúncio:** conferir [`ads-lancamento.md`](./ads-lancamento.md) — copy, segmentação, kill switch.
4. **Toda semana:** abrir [`calendario/90-dias.md`](./calendario/90-dias.md) e seguir o que tá marcado pra hoje.
