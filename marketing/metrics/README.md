## Convenção

Cada KPI tem:
- **Definição:** o que exatamente está sendo medido.
- **Fonte:** de onde vem o número (PostHog, Stripe, manual, etc.).
- **Meta:** o número-alvo.
- **Frequência:** diária, semanal, mensal.
