# Domain docs

This repository uses a single domain context.

Before domain work, read `CONTEXT.md`, `docs/agents/source-of-truth.md`, and the relevant ADRs under `docs/adr/`. If either canonical file is absent, continue silently.

Use glossary terms as written. Surface any conflict with an ADR instead of silently overriding it. Create new glossary entries or ADRs only when a producer skill resolves a real term or durable trade-off.

Plans under `docs/plans/`, `.planning/`, and GitHub issues are **proposals** until CONTEXT or an ADR absorbs them. Do not treat stale campaign/briefing/cockpit copy in `README.md` as the live spine.
