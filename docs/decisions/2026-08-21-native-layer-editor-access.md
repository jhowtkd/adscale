# Native Layer Editor access

Accepted 2026-08-21. This decision supersedes earlier owner-only access for
product Layer Editor actions and Layerize artifacts: an active workspace
member with an active `layer_editor_v1` entitlement may use the approved
editor and post-processing workflow. Diagnostic ZIP remains owner/ops-only.
Seedream Layerize remains a fail-closed post-processing provider, never an
image-generation route.
