# Skill ADScale (`adscale`)

Fonte canônica: `app/src/mcp/skills/adscale/SKILL.md`, versionada junto com
o MCP server (`app/src/server/mcp/`). Rename de tool = bump da skill no
mesmo release.

A skill no monorepo versiona; **não distribui**. Cópias instaladas (idênticas
ao canônico, sem este README):

- `.cursor/skills/adscale/SKILL.md` (host Cursor)
- `.claude/skills/adscale/SKILL.md` (host Claude)

Após editar o canônico, copie para os dois caminhos e confira com
`diff` — o aceite da spec exige os três idênticos.
