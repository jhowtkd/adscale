# Plan 153-01 - Mismatch Grouping and Rule Candidate Extraction

## Goal

Extract actionable rule candidates from system-human mismatches grouped by bucket and category.

## Acceptance Criteria

- Mismatches group into rule candidates by mismatch bucket and rule category.
- Each candidate includes rationale, supporting signal ids, confidence, and caveats.
- `calibration_rules` table persists candidates with default `candidate` status.
