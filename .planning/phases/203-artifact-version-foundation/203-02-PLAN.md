```typescript
type AdoptArtifactRequest =
  | { artifactType: "plan"; artifactId: string }
  | { artifactType: "creative"; artifactId: string };

interface ThreadArtifactVersionState {
  lineages: Array<{
    lineage: ArtifactLineageSummary;
    approvedCurrent: ArtifactVersionSummary | null;
    working: ArtifactVersionSummary | null;
    versions: ArtifactVersionSummary[];
    pendingProposals: ArtifactProposalSummary[];
    generationStatus: SafeGenerationStatus | null;
  }>;
}
```

The route derives all authority from the authenticated workspace and persisted thread. Request bodies never select workspace/client/campaign.
