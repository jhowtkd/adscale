Create the typed persistence boundary for immutable plan/creative histories, separate approved and working pointers, safe proposal queues, and strict multi-scope enforcement.

Purpose: Later iteration phases need one trustworthy model before they can create revisions, spend credits, or expose approval controls.
Output: Migration, schema, strict contracts, snapshot builders, repository, and focused tests.
</objective>

<interfaces>
Model four separate concepts:

```typescript
type ArtifactType = "plan" | "creative";
type ArtifactOrigin = "legacy_import" | "native" | "revision";

interface ArtifactScope {
  workspaceId: string;
  clientProfileId: string;
  campaignId: string;
  threadId: string;
}

interface ArtifactLineageHead {
  lineageId: string;
  approvedCurrentVersionId: string | null;
  workingVersionId: string | null;
  revision: number;
}
```

Keep plan and creative snapshots as strict discriminated schemas. A proposal is not a committed version.
</interfaces>
