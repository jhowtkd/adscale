# Plan 20-02: Frontend Generation Mode Step Component

## Context

Plan 20-01 created the backend AI suggestion endpoints (`/api/campaigns/[id]/suggest-ctas` and extended campaign deduction). Now we need a dedicated frontend step where users configure advanced generation settings with AI-powered suggestions.

The generation mode step should appear after briefing (step 1) and before the plan/derivations. Currently, generation settings are mixed into BriefingStep - they need to be extracted into a clean, focused component.

## Tasks

### Task 1: Create useGenerationSuggestions hook

Create `app/src/lib/hooks/use-generation-suggestions.ts`:
- `useSuggestCtas(campaignId)` - calls POST /api/campaigns/[id]/suggest-ctas
- `useSuggestCreativeLevel(campaignId)` - calls GET /api/campaigns/[id]/suggest-creative-level (from 20-01)
- Proper error handling, loading states, caching

### Task 2: Create GenerationStep component

Create `app/src/components/workspace/GenerationStep.tsx`:

**Sections:**
1. **Modo de Derivação** - Cards for art_variation, format_adaptation, restyling
2. **Perfil de Criatividade** - Cards/slider for conservative, balanced, bold with descriptions
3. **Formato de Saída** - Toggle buttons for 1:1, 4:5, 9:16 (disabled when format_adaptation selected)
4. **CTA por Peça** - 3 input fields with AI suggestion chips
   - "Usar Sugestões da IA" button to apply all
   - Each field shows suggestions as clickable chips
   - Loading state while fetching suggestions

**Props:**
```typescript
interface GenerationStepProps {
  campaignId: string;
  initialData?: {
    generationMode?: "art_variation" | "format_adaptation" | "restyling";
    creativeLevel?: "conservative" | "balanced" | "bold" | "extreme";
    targetFormats?: string[];
    ctaVariants?: [string, string, string];
  };
  onContinue: (data: GenerationConfig) => void;
  onBack: () => void;
}
```

### Task 3: Extract generation settings from BriefingStep

Remove from `BriefingStep.tsx`:
- `generationMode` field and selector
- `creativeLevel` field and selector  
- `targetFormats` field and selector
- `ctaVariants` field and inputs
- Keep only: name, client, clientProfileId, objective, audience, platforms, tone, offer, constraints, notes

Update `BriefingFormData` interface to remove generation fields.

### Task 4: Integrate GenerationStep into workspace

Update `useCampaignWorkspace.ts`:
- Add generation state between briefing and upload
- Update step navigation labels
- Handle generation config save

Update the campaign workspace page to render GenerationStep at the appropriate step.

### Task 5: Add i18n translations

Add to `app/messages/pt-BR.json` and `app/messages/en.json`:
- generationMode section labels
- creativity profile descriptions
- CTA suggestion labels
- Format labels
