# Plan 20-03: Frontend Flow Integration and Translations

## Goal

Wire AI-powered suggestions into the generation flow, fix navigation bugs, and ensure all UI strings are properly translated.

## Context

- Plan 20-01 built backend AI suggestion endpoints (`/api/campaigns/:id/suggest-ctas`, `/api/campaigns/:id/suggest-creative-level`)
- Plan 20-02 built the `GenerationStep` UI component with CTA suggestions integration
- The `useSuggestCreativeLevel` hook exists but is NOT used in `GenerationStep`
- `handleGenerateDerivations` has a navigation bug: goes to step 4 (Plan) instead of step 5 (Gallery)
- UploadStep buttons allow bypassing GenerationStep, which may lead to generation with unset config

## Tasks

### Task 1: Integrate AI creative level suggestion into GenerationStep

- Import and use `useSuggestCreativeLevel` hook in `GenerationStep.tsx`
- Display suggestion badge when AI recommends a creativity profile
- Show reasoning text from AI response
- Add "Apply suggestion" button to set the suggested level
- Auto-fetch suggestion on mount (similar to CTA suggestions)
- Handle loading and error states gracefully

**Done when:**
- [ ] AI creative level suggestion appears as a clickable badge
- [ ] User can apply the suggestion with one click
- [ ] Loading state shown while fetching
- [ ] Errors handled silently (user can still select manually)

### Task 2: Fix derivation generation navigation

- In `use-campaign-workspace.ts`, change `goToStep(4)` to `goToStep(5)` in `handleGenerateDerivations`
- Ensure `handleGeneratePreview` does not navigate away (preview should stay on current step)
- Verify `handleSkipPlan` navigates correctly after generation

**Done when:**
- [ ] After generating derivations, user lands on Gallery (step 5)
- [ ] Preview generation stays on current step
- [ ] No navigation regressions in other flows

### Task 3: Fix UploadStep flow to require GenerationStep

- In `UploadStep.tsx`, change "Skip Plan" button to navigate to GenerationStep instead of generating directly
- In `UploadStep.tsx`, change "Generate Preview" button to navigate to GenerationStep instead of generating directly
- Keep "Continue to Plan" button but ensure it goes to GenerationStep (step 3)
- Update button labels to reflect actual navigation

**Done when:**
- [ ] UploadStep buttons navigate to GenerationStep
- [ ] Users cannot generate without configuring generation settings first
- [ ] Button labels match actual behavior

### Task 4: Add missing translations

- Add translation keys for creative level suggestion UI:
  - `generation.aiSuggestion`
  - `generation.suggestedByAi`
  - `generation.applySuggestion`
  - `generation.suggestionReasoning`
- Update PT-BR and EN translation files
- Ensure all new UI strings use `useTranslations`

**Done when:**
- [ ] All new UI strings have translations in both PT-BR and EN
- [ ] No hardcoded strings in modified components
- [ ] Build passes without i18n errors

### Task 5: Verify flow end-to-end

- Run build to check for TypeScript errors
- Verify GenerationStep renders correctly with suggestions
- Verify navigation flow: Upload → Generation → Plan → Gallery
- Verify generation uses configured settings

**Done when:**
- [ ] Build passes cleanly
- [ ] Flow works without errors
- [ ] All tasks committed

## Verification

1. Open a campaign, upload a creative
2. Navigate to GenerationStep
3. Verify AI suggests a creativity level with reasoning
4. Apply the suggestion and verify it updates the selection
5. Continue to Plan, approve, and generate
6. Verify landing on Gallery step after generation
7. Check translations in both PT-BR and EN

## Success Criteria

- AI creative level suggestion is visible and actionable in GenerationStep
- Generation flow navigation is correct (Upload → Generation → Plan → Gallery)
- All UI strings are translated
- Build passes without errors
