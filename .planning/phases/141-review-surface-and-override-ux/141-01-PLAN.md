# Plan 141-01 - Workspace Review UI and Decision Language

## Goal

Make the workspace review surface read like an art-direction table: Olhar first, Exportacao second, human decision language explicit.

## Acceptance Criteria

- `DerivationCard` shows `Olhar` and `Exportacao` as separate signals.
- `Sem opiniao` and `Confusa` are visibly blocked from normal approval/package flow.
- `DerivationReviewSheet` prioritizes creative verdict, direction note, what works and what blocks.
- Export/compliance details are secondary/collapsed.
- Numeric score remains available only as a secondary/detail signal.
- Decision controls use `Entra`, `Quase - regenerar assim`, and `Nao entra`.
- Reject/regenerate decisions capture a structured direction reason.

## Tasks

### 141-01-01 - Card-level Olhar/Exportacao badges

**Requirement:** REVIEW-01

- Add compact display helpers for `olharVerdict` and `exportStatus`.
- Replace score-first row priority with Olhar-first signal.
- Show package eligibility hint for `sem_opiniao`, `confusa`, and `bloqueado`.
- Keep score detail visually secondary.
- Add component coverage for ready, quase, blocked and missing-verdict states.

### 141-01-02 - Review sheet information architecture

**Requirement:** REVIEW-02

  2. `Olhar` verdict + axes;
  3. direction note;

  5. decision controls;

**Files likely touched:**

### 141-01-03 - Structured decision language in client mutation

**Requirement:** REVIEW-03

- Extend `useReviewDerivation` to accept:
  - `decision: "entra" | "quase_regenerar" | "nao_entra"`;
  - optional legacy `status`;
  - `directionReason` for regenerate/reject;
  - `overrideReason` for blocked approval attempt.
- Map decisions conservatively:
  - `entra` -> status `approved`;
  - `nao_entra` -> status `rejected`;
  - `quase_regenerar` -> status `rejected` plus regeneration reason or trigger existing regenerate flow.
- Preserve existing callers during migration.
- Add hook/component tests for payload shape and validation UX.

**Files likely touched:**

- `app/src/lib/hooks/use-review.ts`
- `app/src/lib/hooks/use-review.test.tsx`
- call sites in campaign/workspace components
