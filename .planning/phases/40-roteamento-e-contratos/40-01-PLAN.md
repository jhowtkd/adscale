## Goal

Replace silent auto-generation from the Derivar chooser with an explicit flow state machine: chooser → intent-specific shell config modal. Migrate chooser copy to next-intl (DRV-08). No backend changes.

## Requirements Mapping

| Requirement | Coverage |

| DRV-07 | Tasks 1–4: hook, page wiring, shell modals, no `configureAndGenerate` from chooser |

2. `useDerivationFlow` tracks `activeStep` and routes to exactly one surface at a time
3. Each of the four intents opens the correct shell modal with distinct title
4. Back from shell modal reopens Derivar chooser; Cancel closes entire flow
5. All Derivar chooser strings come from `workspace.derivar` in PT-BR and EN
6. Typo "Variir tamanhos" fixed in user-visible copy
7. Shell modals have Back + Cancel only — no Confirm button in Phase 40
8. Estilizar modal path unchanged
9. New unit tests pass; existing test suite still green

## Task 1: Create `useDerivationFlow` hook

**File:** `app/src/lib/hooks/use-derivation-flow.ts`

Implement:

```typescript
export type DerivationIntent =
  | "manual_art"
  | "auto_art"
  | "single_format"
  | "batch_format";

export type DerivationFlowStep = "chooser" | DerivationIntent;
```

State:
- `activeStep: DerivationFlowStep | null` — `null` = flow closed

Actions:
- `openChooser()` → `activeStep = "chooser"`
- `selectIntent(intent)` → `activeStep = intent` (must not side-effect generate)
- `backToChooser()` → `activeStep = "chooser"`
- `closeFlow()` → `activeStep = null`

Derived booleans:
- `isChooserOpen = activeStep === "chooser"`
- `isArtConfigOpen = activeStep === "manual_art" || activeStep === "auto_art"`
- `isFormatConfigOpen = activeStep === "single_format" || activeStep === "batch_format"`
- `selectedIntent` = intent when on config step, else null

**Verify:** `<automated>cd app && npm test -- --run src/lib/hooks/use-derivation-flow.test.ts`</automated>

</task>
