# Plan 147-01 - Decision Artifact Completion and Safe Event Recording

## Goal

Prepare and apply Jhonatan's decisions for the current review-ready Cenbrap calibration rows, using the existing idempotent recorder and preserving a truthful blocker when decisions are not supplied.

## Acceptance Criteria

- Every current `review_ready` row has either:
  - a Jhonatan decision (`entra`, `quase`, `nao_entra`); or
  - an explicit `manual_pending` / `human_needed` blocker.
- Decisions include reviewer and reviewedAt.
- Decision ids match derivation ids in `142-CENBRAP-CALIBRATION.json`.
- Recorder dry-run validates the artifact before any DB write.
- Recorder confirm is run only when decisions are real, intentional and reviewed.
- Planning artifacts do not contain prompts, signed URLs, `DATABASE_URL` or raw secret payloads.

## Tasks

### 147-01-01 - Reconcile current decision rows

**Requirements:** HUMDEC-01

- Read current `142-CONTACT-SHEET.md`, `142-CENBRAP-CALIBRATION.json` and `145-DECISIONS.template.json`.
- If `145-DECISIONS.json` exists, validate it against the current calibration ids.
- If it does not exist, create a Phase 147 run note that lists the exact rows awaiting Jhonatan decisions and points to the template.
- Do not pre-fill decision values from `olharVerdict` or `exportStatus`.

**Files likely touched:**

- `.planning/phases/147-operator-decision-session-and-calibration-rerun/147-DECISION-RUN.md`
- `.planning/phases/145-jhonatan-decision-capture-and-mismatch-triage/145-DECISIONS.json` (only if Jhonatan provides real decisions)

### 147-01-02 - Recorder dry-run and optional confirm

**Requirements:** HUMDEC-02

- Run recorder dry-run against the chosen input artifact.
- If and only if decisions are supplied by Jhonatan, run the recorder with `--confirm`.
- Capture command, status, event ids or human blocker in `147-DECISION-RUN.md`.
- Confirm idempotency behavior prevents duplicate event insertion or makes latest-event semantics explicit.

**Files likely touched:**

- `.planning/phases/147-operator-decision-session-and-calibration-rerun/147-DECISION-RUN.md`

### 147-01-03 - Safety scan

**Requirements:** HUMDEC-02

- Scan Phase 145 and Phase 147 artifacts for:
  - `DATABASE_URL`;
  - postgres URLs;
  - signed URL signatures;
  - prompt payload markers.
- Record any hit and whether it is benign.

**Files likely touched:**
