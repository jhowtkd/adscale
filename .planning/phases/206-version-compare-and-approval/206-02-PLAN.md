<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to acknowledgement/promote routes | Untrusted IDs, expected revisions, operation IDs, and acknowledgement IDs request canonical writes. |
| service to repository transaction | Eligibility/effects must be revalidated against rows read inside the transaction. |
| artifact snapshot to canonical tables | Immutable allowlisted plan/creative fields become mutable product state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-206-07 | Elevation of privilege | IDOR / scope checks in acknowledgement and promotion routes | mitigate | Derive workspace/client/campaign/thread scope from auth and persisted thread; scope every lineage/version/receipt query. |
| T-206-08 | Spoofing | forged comparison acknowledgement | mitigate | Persist a server-created receipt bound to target versions, plan lineage, and exact head revision; reject client booleans and mismatches. |
| T-206-09 | Tampering | stale CAS approval race | mitigate | Require expected revision for every changed head and perform conditional CAS inside the transaction with no retry. |
| T-206-10 | Tampering | atomic compound rollback | mitigate | One Drizzle transaction owns both CAS operations, canonical writes, proposal staling, and event inserts; any failure throws and rolls back. |
| T-206-11 | Tampering | unsafe status promotion | mitigate | Closed eligibility allowlist is `ready` or proven previously-approved; fail closed for unknown/stale/superseded/nonterminal generation states. |
| T-206-12 | Information disclosure | route/conflict DTOs | mitigate | Positive response schemas exclude prompts, provider payloads, output keys, technical provenance, and persisted signed URLs. |
| T-206-13 | Repudiation | repeated promotion | mitigate | Unique operation-bound append-only approval events make successful transitions traceable and replay-idempotent. |
| T-206-SC | Tampering | package supply chain | mitigate | No install task exists; use current Drizzle, Zod, Next route, and repository patterns. |
</threat_model>
