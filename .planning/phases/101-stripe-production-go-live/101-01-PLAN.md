# Plan 101-01: Stripe Production Go-Live

## Objective

Configure and prove production Stripe billing through an operator-repeatable checklist and captured live evidence.

## Must Haves

- A repository checklist covers production keys, price IDs, app URLs, webhook endpoint/events, portal configuration, deploy order, rollback, and evidence capture.
- Secrets are referenced by environment variable name only.
- Production webhook signature verification and event processing are proven with a real signed event.
- Checkout and portal sessions are created against the intended production configuration using a controlled operator account.

## Tasks

### Task 1: Write and preflight the go-live runbook

Document required Render and Stripe configuration, compare it with env validation and `server/billing/plans.ts`, and make `scripts/seed-stripe-real.ts` safe and repeatable for the intended mode.

### Task 2: Deploy production billing configuration

Apply configuration, deploy the app, verify health, billing status, checkout creation, portal creation, and webhook endpoint availability.

### Task 3: Execute signed webhook smoke

Trigger controlled checkout/invoice events, confirm one-time processing and ledger effects, and record event IDs, deploy ID, timestamps, and redacted outcomes in a verification artifact.

## Verification

- Production health and billing route smoke pass.
- Stripe dashboard and application evidence agree on customer, subscription, invoice, and single credit grant.
- No secret values are committed.
