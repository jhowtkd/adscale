# Plan 148-01 - Reviewable-Row Sourcing and Sample Expansion

## Goal

Move the Cenbrap calibration sample from 2 reviewable rows toward at least 5 human-decision rows, or document an exact blocker when the rows or decisions are unavailable.

## Acceptance Criteria

- Current row inventory separates:
  - reviewable rows;
  - rows with human decisions;
  - rows still `manual_pending`;
  - source labels.
- At least 5 rows are available for Jhonatan decision capture, or a blocker explains what prevents that.
- Added rows have safe refs, dual verdicts and explicit source labels.
- The plan does not call `synthetic_fixture` customer-real evidence.
- Jhonatan decision input covers every row that is intended to count toward sample sufficiency.

## Tasks

### 148-01-01 - Inventory current sample and blocker

**Requirements:** SAMPLE-01, SAMPLE-04

- Run corpus inspection and read current calibration/contact sheet.
- Create `148-SAMPLE-RUN.md` with:
  - current reviewable row count;
  - human decision count;
  - missing human decision count;
  - current sample guidance;
  - current source composition.
- Record that the baseline is `0/5`, not `2/5`, because reviewable rows without decisions do not count.

**Files likely touched:**

- `.planning/phases/148-sample-sufficiency-expansion/148-SAMPLE-RUN.md`

### 148-01-02 - Expand or block reviewable rows

**Requirements:** SAMPLE-01, SAMPLE-04

  - extend the fixture/import path to create at least 3 additional `synthetic_fixture`/`operator_imported` reviewable rows; or
  - document `operator_data_unavailable` / `insufficient_reviewable_rows` with exact missing prerequisite.
- If code is needed, reuse existing patterns in `seed-cenbrap-calibration-corpus.ts`:
  - dry-run default;
  - `--confirm` required for DB writes;
  - manifest with source labels;
  - no secrets or signed URLs in artifacts.
- Write a Phase 148 source manifest instead of silently mutating Phase 144's manifest.

**Files likely touched:**

- `app/scripts/seed-cenbrap-calibration-corpus.ts` or `app/scripts/seed-cenbrap-calibration-sample.ts`
