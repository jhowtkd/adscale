    - resolveCtaSemantics("Comprar agora", "art_variation") → { kind: "explicit", text: "Comprar agora" }

    - resolveCtaSemantics(undefined, "restyling") → { kind: "inherited" }
  </behavior>
  <action>
Create `app/src/server/ai/creative-contract.ts` as a new file. Export:

1. `CtaSemantics` discriminated union:
```ts
export type CtaSemantics =
  | { kind: "explicit"; text: string }
  | { kind: "inherited" }
  | { kind: "absent" };
```

2. `CreativeContract` interface (per D-01 in CONTEXT.md — CNTR-01 locked decision):
```ts
export interface CreativeContract {
  generationMode: "art_variation" | "format_adaptation" | "restyling";
  targetFormat: string;
  ctaSemantics: CtaSemantics;
  baseAssetId: string | null;
  styleAssetId: string | null;
  client: string | null;
  product: string | null;
  offer: string | null;
  constraints: string | null;
}
```

3. `resolveCtaSemantics(ctaText: string | null | undefined, mode: CreativeContract["generationMode"]): CtaSemantics` — per CNTR-03 locked decision:
- If `ctaText` is a non-empty string → `{ kind: "explicit", text: ctaText }`
- Otherwise (null, undefined, empty string) for any mode → `{ kind: "inherited" }`
- `absent` is NOT surfaced in v11.1; resolver never returns it (reserved for future explicit opt-out)

No imports needed — pure type module.
