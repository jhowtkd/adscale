## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→API | Untrusted draft text and cancel requests |
| orchestrator→action card | Display metadata must not execute writes without confirm |
| stale UI→confirm API | Client may attempt confirm on stale card |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-204-06 | I | plan-revisions draft route | mitigate | Authenticated thread lookup; workspace/client scope from server record |
| T-204-07 | I | cancel route | mitigate | Proposal scope predicates; only pending → canceled transition |
| T-204-08 | T | stale card confirm | mitigate | UI warns but server confirm handler from 204-01 rejects stale proposals |
| T-204-09 | S | action card display | mitigate | Render summary from server-built display object only; no raw HTML from user feedback |
| T-204-10 | D | orchestrator branch | accept | Proposal creation is synchronous; no background job duplication surface in this phase |
</threat_model>
