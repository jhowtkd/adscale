<interfaces>

New response shape should be close to:

```ts
export type ProgressionLevelKey =
  | "aprendiz"
  | "analista_criativo"
  | "estrategista_ads"
  | "cientista_ads";

export type ProgressionEvidenceKey =
  | "campaign_created"
  | "base_creative_uploaded"
  | "readiness_ran"
  | "derivation_generated"
  | "creative_approved"
  | "creative_exported"
  | "share_created";

export interface WorkspaceProgressionResponse {
  level: {
    key: ProgressionLevelKey;
    label: string;
    shortLabel: string;
    description: string;
  };
  progressPercent: number;
  completed: Array<{
    key: ProgressionEvidenceKey;
    label: string;
    completedAt: string;
    evidenceId?: string;
    evidenceType?: string;
  }>;
  nextAction: {
    key: ProgressionEvidenceKey;
    label: string;
    description: string;
    href: string;
    blocked: boolean;
    blockedReason?: string;
  };
  lastCalculatedAt: string;
}
```

The exact type names are flexible, but the route must return enough data for Plan 68-02 without requiring the UI to know database details.
