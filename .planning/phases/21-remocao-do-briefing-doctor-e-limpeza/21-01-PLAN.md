Delete `app/src/lib/hooks/use-briefing-doctor.ts` entirely.

### Task 1.3: Delete briefing-doctor API route

Delete `app/src/app/api/briefing-doctor/analyze/route.ts` entirely.

This is the POST endpoint that accepts briefing data and returns AI analysis.

### Task 1.4: Update middleware rate limiting

Edit `app/src/middleware.ts` to remove the `/api/briefing-doctor` branch from the rate limit category check.

Current code (line 36):
```typescript

```

Remove this line so `/api/briefing-doctor` no longer gets special "ai" category rate limiting (the route won't exist anyway).

### Task 1.5: Delete briefing-doctor test files

Delete these test files entirely:
- `app/tests/unit/briefing-doctor.test.ts`
- `app/tests/unit/briefing-doctor-ui.test.tsx`
