    - Path B fail: missing acceptedAt or rationale on caveat

    - learningImpactMetrics.status insufficient_sample does not add QA-24 errors when visual path satisfied
  </behavior>

Export testable helpers from checker (e.g. `assertQa24(evidence, errors)` and `validateMetricSeparation(evidence, errors)`) — use `.mjs` export or thin `real-quality-release-evidence-guard.ts` if import ergonomics require it; prefer exporting from checker via refactor to shared `real-quality-release-evidence-guard.mjs` only if needed.

Implement `assertQa24` per RESEARCH Pattern 3:
- Primary metric: `qualityMetrics.humanCorpus.meanHumanVisualScore` (NOT fixture meanQualityScore)

- Factual hard gates: `factualMetrics.humanCorpusFactualPassRate === 1.0` and `factualMetrics.v12_3FactualFidelityRate === 1.0` — no caveat override
