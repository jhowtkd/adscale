# Plan 144-02 - Dual-Verdict Readiness and Live Calibration Rerun

## Goal

Turn the seeded/imported Cenbrap corpus into a contact sheet that is actually ready for Jhonatan's judgment.

## Acceptance Criteria

- Reviewable derivations have safe `outputKey`, `olharVerdict` and `exportStatus`.
- Rows missing dual verdict are counted and routed to QA/regeneration before Phase 145.
- Live calibration is rerun without `--template`.
- `142-CENBRAP-CALIBRATION.json` has `mode=live` and `evaluatedCampaignCount >= 2`, or `144-BLOCKERS.md` explains why not.
- `142-CONTACT-SHEET.md` has `review_ready > 0` rows, or Phase 145 remains blocked.
- Agreement rate and quality claims remain withheld.

## Tasks

### 144-02-01 - Dual-verdict readiness pass

**Requirements:** CORPUS-03

- Inspect every candidate derivation for:
  - `outputKey`;
  - `isPreview=false`;
  - `olharVerdict`;
  - `exportStatus`;
  - package eligibility context.
- For rows missing verdicts, choose one:
  - run existing QA/dual-verdict path if the output is real and safe;
  - update from approved operator fixture payload only if explicitly labeled;
  - exclude from review and record `missing_dual_verdict`.
- Document row counts in `144-CORPUS-RUN.md`.

**Files likely touched:**

- `app/scripts/seed-cenbrap-calibration-corpus.ts`
