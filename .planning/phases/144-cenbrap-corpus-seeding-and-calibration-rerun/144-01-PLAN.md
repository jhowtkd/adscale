# Plan 144-01 - Corpus Source Inspection and Safe Seeding Path

## Goal

Find or create the minimum Cenbrap corpus needed for real calibration without pretending synthetic data is customer evidence.

## Acceptance Criteria

- Target environment and workspace are documented without exposing secrets.
- Existing campaigns are inspected before creating any seed/import data.
- If campaigns already exist but matcher misses them, the mismatch is documented and fixed or routed.
- If no campaigns exist, an idempotent seed/import path is available with dry-run by default.
- At least two Cenbrap campaigns exist with source labels, or `144-BLOCKERS.md` records `operator_data_unavailable`.
- No prompts, signed URLs, credentials or real customer payloads are persisted in planning artifacts.

## Tasks

### 144-01-01 - Target environment and corpus inspection

**Requirements:** CORPUS-01

- Reconfirm the live calibration target:
  - shell `DATABASE_URL` present/absent;
  - `app/.env.local` `DATABASE_URL` present/absent;
  - selected source;
  - secret_exposed=false.
- Add a small inspection step that counts:
  - workspaces scanned;
  - candidate campaigns containing Cenbrap-like signals;
  - campaigns with output derivations;
  - campaigns with dual verdict coverage.
- Write results to `144-CORPUS-RUN.md`.

**Files likely touched:**

- `.planning/phases/144-cenbrap-corpus-seeding-and-calibration-rerun/144-CORPUS-RUN.md`
- `.planning/phases/144-cenbrap-corpus-seeding-and-calibration-rerun/144-BLOCKERS.md`

### 144-01-02 - Idempotent seed/import path

**Requirements:** CORPUS-01, CORPUS-02

- If no existing campaigns are usable, add an operator script such as `app/scripts/seed-cenbrap-calibration-corpus.ts`.
- Script requirements:
  - `--dry-run` default or explicit `--confirm` required for writes;
  - target workspace selection by id/email/first workspace, documented safely;
  - idempotent cleanup/update by stable campaign names or seed marker;
  - source labels per row: `real_customer`, `operator_imported`, `synthetic_fixture`;
  - writes a manifest to `144-CORPUS-MANIFEST.json`.
- Do not reuse TestSprite identity or generic visual-foundations labels for Cenbrap evidence.

**Files likely touched:**

- `app/scripts/seed-cenbrap-calibration-corpus.ts`
- `.planning/phases/144-cenbrap-corpus-seeding-and-calibration-rerun/144-CORPUS-MANIFEST.json`
- `.planning/phases/144-cenbrap-corpus-seeding-and-calibration-rerun/144-CORPUS-RUN.md`

**Requirements:** CORPUS-02
