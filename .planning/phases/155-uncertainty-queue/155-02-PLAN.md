# Plan 155-02 - Human Review Queue and Batch Decision UX

## Goal

Build a capped human review queue that routes only teachable uncertainty without becoming a permanent manual pipeline.

## Acceptance Criteria

- `buildReviewQueue()` returns 5–15 items sorted by uncertainty score.
- `shouldSkipHumanReview()` skips review for low uncertainty on calibrated brands.
- Each queue item includes a teachable summary.
