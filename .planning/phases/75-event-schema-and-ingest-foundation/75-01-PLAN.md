**`beta_sessions`** (DDL only — no CRUD APIs this phase per D-03):
- `id` uuid PK default random
- `workspace_id` uuid NOT NULL FK → workspaces ON DELETE CASCADE
- `cohort_label` text nullable
- `assistance_level` text NOT NULL — values `hands_on` | `observe_only` (text + Zod later; no pgEnum per repo convention)
- `started_at` timestamp NOT NULL default now
- `ended_at` timestamp nullable
- `operator_notes` jsonb NOT NULL default `{}` — stage-keyed object
- `created_at`, `updated_at` timestamps NOT NULL default now
- Index on `workspace_id`

**`beta_analytics_events`** (append-only per D-01):
- `id` uuid PK
- `workspace_id` uuid NOT NULL FK → workspaces ON DELETE CASCADE
- `user_id` text NOT NULL FK → user ON DELETE CASCADE
- `session_id` uuid nullable FK → beta_sessions ON DELETE SET NULL (per D-04)
- `event_key` text NOT NULL (snake_case, max 64 chars enforced at API layer)
- `properties` jsonb NOT NULL default `{}`
- `source` text NOT NULL default `'client'` — `'client'` | `'server'` for Phase 78 debugging (research recommendation)
- `campaign_id` uuid nullable FK → campaigns ON DELETE SET NULL (discretion: match feedback_reports)
- `derivation_id` uuid nullable FK → derivations ON DELETE SET NULL
- `created_at` timestamp NOT NULL default now
- Indexes: `(workspace_id, created_at)`, `(session_id)`, `(workspace_id, event_key, created_at)`
