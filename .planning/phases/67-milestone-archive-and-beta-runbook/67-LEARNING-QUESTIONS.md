# v11.7 Learning Questions (BETA-03)

**Captured:** 2026-06-05 — before any larger v11.7 feature build  
**Source:** v11.6 cockpit beta readiness work

Answer these from the **first 3–5 beta sessions** before prioritizing v11.7 scope.

## Readiness & briefing

1. Do readiness blocking rules match operator judgment, or do users override/ignore them?
2. Which guided briefing questions get skipped most — signal weak templates or wrong ordering?
3. Is one readiness analysis enough per asset, or do users rerun often (credit sensitivity)?

## Recipes & preview

4. Which recipe wins by default vs which operators actually choose?
5. Does preview quality predict batch satisfaction, or is preview a false confidence step?
6. Are tradeoff copy blocks read, or do users jump straight to overrides?

## Delivery & credits

7. Do clients use share links without operator hand-holding?
8. Where do credit surprises happen — readiness, preview, or batch estimate?
9. Is approval package refresh (stale badge) understood or treated as a bug?

## Process

10. What is median time draft → share link, and where does it stall?

## Decision gate

- If **Q4–Q6** show preview/recipe mismatch → prioritize recipe/preview iteration in v11.7.
- If **Q7–Q9** dominate → prioritize delivery/billing UX before new AI features.
- If **Q1–Q3** dominate → invest in readiness/briefing accuracy before new surfaces.
