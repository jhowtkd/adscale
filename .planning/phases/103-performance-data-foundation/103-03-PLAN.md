# Plan 103-03: Secure Performance Service and API

## Objective

Expose one secure canonical write/read boundary that Phase 104 can reuse for both manual and CSV ingestion.

## Must Haves

- Server derives and validates workspace/client/campaign/derivation relationships instead of trusting duplicated client input.
- Manual and future CSV paths can call the same service contract.
- Cross-workspace, cross-campaign and mismatched-client references are rejected before persistence.
- API returns raw and derived metrics without coercing exact numeric strings.
- Phase remains limited to canonical single-snapshot operations, not CSV/import history UI.
