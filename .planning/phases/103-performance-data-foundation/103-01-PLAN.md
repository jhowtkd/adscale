# Plan 103-01: Canonical Performance Contracts

## Objective

Define the pure, deterministic contract for performance snapshots before persistence or HTTP code exists.

## Must Haves

- Raw metrics distinguish valid zero values from absent derived metrics.
- CTR, CPC, CPA and ROAS never return `Infinity`, `NaN` or fabricated zero fallbacks.
- Platform, placement, source scope, period and money/count types express the Phase 103 context decisions.
- Source identity is deterministic when optional account/external IDs are missing.
- Placement normalization preserves the raw provider label.
