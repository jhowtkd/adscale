# Plan 103-02: Performance Schema and Repository

## Objective

Persist canonical snapshots with database-enforced integrity, auditability and atomic source-key upsert semantics.

## Must Haves

- Schema represents derivation + platform + placement + inclusive period, source timezone and explicit total/segment scope.
- Exact numeric types preserve spend, conversions and conversion value without JavaScript floating-point coercion.
- Database constraints reject negative metrics and reversed periods.
- Unique workspace/source-key identity supports safe create-or-update behavior even when account IDs are absent.
- All repository queries and mutations include workspace scope.
