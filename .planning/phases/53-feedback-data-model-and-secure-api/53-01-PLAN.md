# Plan 53-01: Feedback data model and secure create API

## Goal

Add durable feedback report persistence and a workspace-safe create endpoint with diagnostic sanitization and structured logging.

## Must Haves

- Feedback report table with status, type, severity, category, message, workspace/user FKs, optional campaign/derivation FKs, asset refs and diagnostic jsonb.
- POST /api/feedback/reports requires authenticated workspace access.
- Cross-workspace campaign, derivation, and asset references are rejected server-side.
- Diagnostic payload is bounded and strips sensitive keys.
- Server logs use IDs only on create success and validation failure.
