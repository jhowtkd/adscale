# Plan 152-02 - Evidence Level and Source Composition Audit

## Goal

Declare explicit evidence level and source composition on brand taste profiles so fixture-only data cannot masquerade as customer-real validation.

## Acceptance Criteria

- `computeEvidenceLevel()` returns `uncalibrated`, `seed_calibrated`, `assisted`, or `evidence_backed`.
- `computeSourceComposition()` counts signals by source label.
- `buildEvidenceCaveats()` surfaces fixture-only and low-sample warnings.

## Tasks

### 152-02-01 - Evidence level and caveats

**Requirements:** PROFILE-03, PROFILE-04

- Attach caveats when fixture-only or insufficient comparable decisions.
