# Plan 146-01 - Live Evidence Refresh and Release Gate Rerun

## Goal

Generate live Olhar release evidence from the latest Cenbrap calibration artifact and run the release checker without converting missing human judgment into a false pass.

## Acceptance Criteria

- A generated live evidence artifact exists at `.planning/phases/142-cenbrap-calibration-and-release-evidence/142-EVIDENCE.json`.
- The artifact consumes `.planning/phases/142-cenbrap-calibration-and-release-evidence/142-CENBRAP-CALIBRATION.json`, not the template evidence.
- Evidence includes agreement, mismatch, missing-human-decision, sem-opiniao, export-block and approved-invalid-prevention counters.
- Evidence status is `human_needed`, `insufficient_sample`, `tech_debt` or `ok` based on the current calibration state.
- `agreementRate` remains `null` when sample guidance still requires additional human decisions.
- Release checker passes only if the evidence is internally consistent with the blocker.
- `synthetic_fixture` caveat is carried into the generated evidence notes or companion audit.

## Tasks

### 146-01-01 - Add or wire live evidence builder

**Requirements:** CLAIM-01

- Check whether an existing CLI already writes live Olhar release evidence.
- If missing, add `app/scripts/build-olhar-release-evidence.ts`.
- Script behavior:
  - reads `--calibration`;
  - writes `--output`;
  - calls `buildOlharReleaseEvidence` or equivalent canonical builder;
  - refuses template calibration unless an explicit template mode is requested;
  - preserves blocker details and source caveats;
  - does not write secrets, prompts, signed URLs or raw payloads.
- Update `app/package.json` only if a durable `olhar-release-evidence:build` script is useful for operators.

**Files likely touched:**

- `app/scripts/build-olhar-release-evidence.ts`
- `app/package.json`
- `.planning/phases/142-cenbrap-calibration-and-release-evidence/142-EVIDENCE.json`

### 146-01-02 - Rerun release checker against live evidence

**Requirements:** CLAIM-02

- Run the checker against generated live evidence.
- Confirm the status matches current truth:
  - `human_needed` when reviewable rows exist but Jhonatan decisions are missing;
  - `insufficient_sample` when decisions exist but sample guidance is still below threshold;
  - `ok` only when human decisions and sample guidance allow claims;
  - `tech_debt` only when unresolved operator blockers must be carried forward.
- Confirm any quality/agreement claim remains withheld when `additionalNeeded > 0`.

**Files likely touched:**

- `.planning/phases/146-evidence-refresh-and-claims-gate/146-EVIDENCE-RUN.md`

### 146-01-03 - Focused tests and evidence consistency scan

**Requirements:** CLAIM-01, CLAIM-02

- Run focused Olhar evidence tests.
- Inspect generated JSON for:
  - status;
  - `artDirectionMetrics`;
  - `factualExportMetrics`;
  - `sampleGuidance`;
  - blocker details;
  - source caveats.
- Record commands and result in `146-EVIDENCE-RUN.md`.

**Files likely touched:**

- `.planning/phases/146-evidence-refresh-and-claims-gate/146-EVIDENCE-RUN.md`

## Stop Conditions

- Do not proceed if evidence is generated from template data while the plan claims live calibration.
- Do not set `agreementRate` when sample guidance blocks the claim.
- Do not call the phase `ok` with `decisionCount=0`.
- Do not remove the `synthetic_fixture` caveat.
