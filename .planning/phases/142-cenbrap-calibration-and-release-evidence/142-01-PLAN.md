# Plan 142-01 - Cenbrap Real-Campaign Calibration Run

## Goal

Create a repeatable calibration run over real Cenbrap campaigns, producing contact sheets and capturing Jhonatan's decisions against system verdicts.

## Acceptance Criteria

- Script can select at least two Cenbrap campaigns when live data exists.
- Script emits a template artifact instead of failing dishonestly when live DB/data is unavailable.
- Contact-sheet markdown groups outputs by campaign and shows `olharVerdict`, `exportStatus`, package eligibility, override marker and human decision columns.
- Operator decisions can be captured as `entra`, `quase`, `nao_entra` with mismatch reason.
- Calibration artifact preserves missing-data states (`missing_dual_verdict`, `missing_human_decision`, `insufficient_sample`) explicitly.
- No signed media URLs, prompts or forbidden payload fields are persisted into planning evidence.

## Tasks

### 142-01-01 - Calibration metric domain

**Requirements:** CALIB-01, CALIB-02

- Add a small calibration module for:
  - campaign row normalization;
  - derivation row normalization;
  - human decision normalization from `output_decision_events`;
  - system/human agreement classification;
  - mismatch reason aggregation;
  - sample guidance.
- Treat rows without `olharVerdict` or `exportStatus` as missing evidence, not as negative or positive verdicts.
- Add fixture tests for:
  - agreement on `pronta` + `entra`;
  - agreement on `confusa` + `nao_entra`;
  - mismatch on `confusa` + `entra`;
  - export `bloqueado` separated from art-direction verdict;
  - override-approved row remains exception evidence.

**Files likely touched:**

- `app/src/server/olhar-calibration/cenbrap-calibration.ts`
- `app/src/server/olhar-calibration/cenbrap-calibration.test.ts`

### 142-01-02 - Run script and artifacts

**Requirement:** CALIB-01

- Add `app/scripts/run-cenbrap-calibration.ts`.
- Inputs:
  - `--all-workspaces` or current workspace filter if existing script patterns require it;
  - `--template`;
  - `--output`;
  - `--contact-sheet`.
- Select campaigns by conservative Cenbrap signals:
  - campaign/client string contains `cenbrap`;
  - client profile name if available;
  - campaign name terms such as `CENBRAP`, `NR1`, `Cenbrap em Dobro` only as supporting signals.
- Write:
  - `.planning/phases/142-cenbrap-calibration-and-release-evidence/142-CENBRAP-CALIBRATION.json` or template;
  - `.planning/phases/142-cenbrap-calibration-and-release-evidence/142-CONTACT-SHEET.md`.
- Include safe output refs only; avoid prompt text and signed URLs.

**Files likely touched:**

- `app/scripts/run-cenbrap-calibration.ts`
- `.planning/phases/142-cenbrap-calibration-and-release-evidence/142-CENBRAP-CALIBRATION.template.json`

### 142-01-03 - Decision capture workflow

**Requirement:** CALIB-02

- Ensure the contact sheet has a manual decision section for each row:
  - `humanDecision`;
  - `mismatchReason`;
  - reviewer;
  - reviewedAt.
- Prefer using `output_decision_events` as canonical source when decisions exist.
- If manual decisions are only in the contact sheet/template, mark them as `manual_pending` until entered.
- Add docs in the contact sheet that Jhonatan's decision is the calibration authority.
