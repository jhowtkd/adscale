# Plan 143-01 - Live Environment Calibration Execution and Artifact Refresh

## Goal

Execute the Cenbrap calibration pipeline against a real database and prove whether the committed evidence can move from template to live rows.

## Acceptance Criteria

- The run command is executed without `--template`.
- The selected environment is documented without exposing `DATABASE_URL`.
- The resulting artifact is inspected for `mode=live`; a template fallback is treated as blocker, not pass.
- `142-CENBRAP-CALIBRATION.json` contains at least two Cenbrap campaigns or records `insufficient_campaigns`.
- `142-CONTACT-SHEET.md` contains real rows with safe refs, dual verdict, export status, package eligibility and override marker, or records why no rows exist.
- No prompt payload, signed URL or secret connection string appears in planning artifacts.

## Tasks

### 143-01-01 - Live environment readiness

**Requirements:** CENLIVE-01

- Identify whether `DATABASE_URL` is available from shell/app env loading without printing the secret value.
- Record the chosen source in `143-LIVE-RUN.md` as:
  - `env_source`: shell, `.env.local`, staging, production or unavailable;
  - `secret_exposed`: false;
  - `run_allowed`: true/false.
- If no usable environment exists, write `143-BLOCKERS.md` with blocker `db_unavailable` and stop before producing a fake pass.

**Files likely touched:**

- `.planning/phases/143-live-cenbrap-calibration-run/143-LIVE-RUN.md`
- `.planning/phases/143-live-cenbrap-calibration-run/143-BLOCKERS.md`

### 143-01-02 - Live calibration run

**Requirements:** CENLIVE-01, CENLIVE-02

- Run:

```bash
cd app && npx tsx scripts/run-cenbrap-calibration.ts \
  --output ../.planning/phases/142-cenbrap-calibration-and-release-evidence/142-CENBRAP-CALIBRATION.json \
  --contact-sheet ../.planning/phases/142-cenbrap-calibration-and-release-evidence/142-CONTACT-SHEET.md
```

- Capture command, timestamp, exit status and non-sensitive summary in `143-LIVE-RUN.md`.
- Treat any produced artifact with `mode=template` as blocker `template_fallback`.
- Treat `mode=live` with fewer than two campaigns as blocker `insufficient_campaigns`, not failure of the implementation.

**Files likely touched:**

- `.planning/phases/142-cenbrap-calibration-and-release-evidence/142-CENBRAP-CALIBRATION.json`
