# Plan 151-02 - Cenbrap Decision Adapter and Idempotency Proof

## Goal

Adapt the existing Cenbrap calibration recorder to write calibration signals alongside output decision events with proven idempotency.

## Acceptance Criteria

- `record-cenbrap-calibration-decisions.ts` writes `calibration_signals` on `--confirm`.
- Adapter maps `output_decision_events` fields to calibration signal payload.
- Repeated imports skip existing signals via calibration idempotency key.
- Dry-run path remains unchanged and does not write signals.
