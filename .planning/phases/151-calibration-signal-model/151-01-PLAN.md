# Plan 151-01 - Calibration Event Contract and Storage Boundary

## Goal

Define the canonical calibration signal contract and persist human judgment events as durable teaching data separate from disposable reviews.

## Acceptance Criteria

- `calibration_signals` table exists with human verdict, system verdict refs, mismatch bucket, source label, reviewer/reviewedAt, and idempotency key.
- Types and normalization enforce allowed verdicts, source labels, and mismatch buckets.
- Recorder inserts signals idempotently via workspace + idempotency key.
- Notes are sanitized; no prompt, signed URL, or secret payloads in stored fields.
