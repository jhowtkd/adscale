# Milestone v11.4: Beta Feedback Capture

**Status:** ✅ SHIPPED 2026-06-05
**Phases:** 53–56
**Total Plans:** 4

## Overview

v11.4 creates a small authenticated feedback capture and owner triage surface for beta users. The diagnostic package is the core value: reports include page, workspace, campaign, derivation, relevant assets, sanitized breadcrumbs, and Sentry/log correlation without leaking unrelated workspace data.

| Phase | Name | Goal | Requirements |
|-------|------|------|--------------|
| 53 | Feedback Data Model and Secure API | Durable report model and secure create API | FBK-02, OBS-03, SEC-01–03 |
| 54 | In-App Feedback Experience and Context Capture | Global/contextual feedback with diagnostics | FBK-01, FBK-03–04, CTX-01–04, OBS-01–02, SEC-04 |
| 55 | Owner Triage and Asset Review | Owner list, detail, status, notes, signed assets | CTX-05, TRI-01–04 |
| 56 | Verification and Privacy Audit | Tests, smoke guidance, privacy handoff | QA-01–03 |

## Phase Details

### Phase 53: Feedback Data Model and Secure API

**Goal:** Create the durable report model and secure create/update foundations.

**Plans:**
- [x] 53-01: Feedback data model and secure create API

**Delivered:** `feedback_reports` schema, migration, repository, sanitization, entity validation, `POST /api/feedback/reports`.

### Phase 54: In-App Feedback Experience and Context Capture

**Goal:** Let beta users submit global/contextual feedback with automatic diagnostic context.

**Plans:**
- [x] 54-01: In-app feedback UI and diagnostic collector

**Delivered:** `FeedbackProvider`, modal, TopBar trigger, campaign/derivation contextual buttons, breadcrumbs, Sentry trace tags.

### Phase 55: Owner Triage and Asset Review

**Goal:** Give the owner a focused internal surface to inspect, filter, annotate and resolve reports.

**Plans:**
- [x] 55-01: Owner triage APIs and `/feedback` page

**Delivered:** Platform owner gate, list/detail/patch APIs, signed asset links, triage UI with completeness chips.

### Phase 56: Verification and Privacy Audit

**Goal:** Prove the flow works end to end and document what is captured or excluded.

**Plans:**
- [x] 56-01: Tests and privacy handoff

**Delivered:** Expanded unit/route tests, `56-HANDOFF.md` with capture/exclude workflow.

## Milestone Summary

**Key Decisions:**
- Feedback lives in authenticated ADScale_2, not the marketing site
- Diagnostic context sanitized server-side; screenshots/replay disabled by default
- Platform owner triage via `PLATFORM_OWNER_EMAILS` / `DEV_ADMIN_EMAIL`
- Asset references only — no copying binaries into feedback storage

**Issues Deferred:**
- Email notifications on new reports (FBK-FUT-02)
- External ticket sync (Linear/Slack/Notion)
- Full session replay rollout

**Technical Debt:**
- No formal v11.4 milestone audit run before ship
- QA-02 browser/mobile smoke documented as manual follow-up
- In-memory breadcrumbs reset on full page reload
