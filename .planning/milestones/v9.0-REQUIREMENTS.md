# Requirements: ADScale v9.0 — Galeria de Revisão v2

**Defined:** 2026-05-27
**Core Value:** Users can go from a single base creative and a brief to multiple platform-ready ad variations in minutes, with full creative control and review.

## v9.0 Requirements

### ANOT — Anotações Visuais

- [x] **ANOT-01**: Usuário pode desenhar livremente em cima da imagem da derivação (freehand drawing)
- [x] **ANOT-02**: Usuário pode adicionar textos em posições específicas da imagem
- [x] **ANOT-03**: Usuário pode adicionar formas geométricas (círculo, retângulo, seta) na imagem
- [x] **ANOT-04**: Anotações são salvas por derivação e persistem entre sessões
- [x] **ANOT-05**: Usuário pode apagar anotações individuais ou limpar todas

### MULTI — Comparação 3+ Derivações

- [x] **MULTI-01**: Usuário pode selecionar 3, 4 ou mais derivações para comparar simultaneamente
- [x] **MULTI-02**: Visualização em grid adaptativo (2x2, 3x3, etc.) baseado na quantidade selecionada
- [x] **MULTI-03**: Cada célula do grid tem zoom/pan independente
- [x] **MULTI-04**: Usuário pode remover uma derivação do grid de comparação
- [x] **MULTI-05**: Metadados visíveis em cada célula do grid

### SLIDER — Slider Antes/Depois

- [x] **SLIDER-01**: Usuário pode comparar duas derivações com slider de divisão arrastável
- [x] **SLIDER-02**: Slider vertical ou horizontal com handle visível
- [x] **SLIDER-03**: Ambos os lados do slider mantêm aspect ratio e posição sincronizada
- [x] **SLIDER-04**: Usuário pode alternar entre modo slider e modo split-pane

## Out of Scope

| Feature | Reason |
|---------|--------|
| Camadas de anotação (layers) | Complexidade de UI alta, anotações simples são suficientes |
| Comparação com a imagem base original | Requer tracking do asset original, fora do escopo |
| Colaboração em anotações (múltiplos usuários) | Requer sistema de colaboração, milestone separado |
| Exportação de imagens com anotações | Feature separada, requer render server-side |
