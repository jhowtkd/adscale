## Locked decisions this plan implements

- **AI-01 / D-provider:** `AssistantModelClient` is the internal boundary; orchestration imports only `assistant/model/client.ts`.
- **AI-02 / D-provider:** MiniMax M3 via OpenAI SDK + `baseURL: https://api.minimax.io/v1`, model `MiniMax-M3` (or `env.MINIMAX_MODEL`), `stream: true`.
- **AI-05 / D-reasoning:** Discard `reasoning`, `thinking`, `reasoning_details`, `reasoning_content`, `chain_of_thought` before yielding events.
- Credentials via env only — never hardcoded (CONTEXT).
