## Locked decisions (AI-03)

- Context is **allowlisted by category** — not raw repo dumps.
- **Always exclude:** secrets, signed URLs, internal evidence, other clients' data in same workspace.
- Scope from `workspaceId` + `clientProfileId` + `threadId` (Phase 178).
- Reasoning/thinking never in context payload (handled at adapter; sanitizer must not re-introduce).

## Allowlist categories (RESEARCH Pattern 3)

| Category | Source | Included shape |
|----------|--------|----------------|
| Client profile | `getClientProfile` | name, industry, tone — no internal IDs beyond scope |
| Campaign | `getCampaignById` when `thread.campaignId` | name, objective, audience, platforms, status — no asset URLs |
| Thread metadata | `getAssistantThreadById` | name, campaign link |
| Recent messages | `listAssistantMessages` (last N, e.g. 20) | role + content; tool messages as summary only |
| Brand kit | `getBrandKit(workspaceId, clientProfileId)` | voice/tone bullets — no file paths |
| Brand memory | `getBrandMemoryContext` | `block` string only (already trimmed) |
