  <name>Implement ToolPolicyGate with deny-by-default</name>
  <files>app/src/server/assistant/tools/policy.ts, app/src/server/assistant/tools/policy.test.ts</files>
  <behavior>
    - Unknown tool `foo` → `{ allowed: false, denialReason: "unknown_tool" }`
    - Invalid JSON arguments → `{ allowed: false, denialReason: "invalid_arguments" }`
    - Zod validation failure → denied with schema error summary
    - Role `member` on `get_thread_context` → allowed
    - Scope mismatch (thread clientProfileId !== ctx.clientProfileId) → denied
    - `propose_action` → `{ allowed: true, requiresConfirmation: true }` with sanitized summary
    - Handler output containing `rawArgs` or `reasoning` → denied at summary sanitization
  </behavior>
  <action>
    Create `policy.ts`:

    ```typescript
    export interface ToolPolicyContext {
      workspaceId: string;
      clientProfileId: string;
      threadId: string;
      userId: string;
    }
    export interface ToolPolicyResult {
      allowed: boolean;
      requiresConfirmation: boolean;
      sanitizedSummary: string;
      denialReason?: string;
      actionRecordId?: string; // when propose_action creates card
    }
    export async function evaluateToolCall(ctx: ToolPolicyContext, call: { name: string; argumentsJson: string }): Promise<ToolPolicyResult>
    ```

    Gate flow (AI-04):
    1. Registry lookup — deny if missing
    2. Parse `argumentsJson` — deny on invalid JSON
    3. Zod safeParse — deny on failure
    4. `requireRole(workspaceId, userId, tool.allowedRoles)` — deny on forbidden
    5. Verify thread scope via `getAssistantThreadById` — deny if clientProfileId mismatch
    6. If `tool.requiresConfirmation`, set flag true before handler
    7. Execute handler; build `sanitizedSummary` string only (no raw args)
    8. Run `containsDeniedPersistenceKeys` on any snapshot objects — deny if hit

    Write `policy.test.ts` with mocked `requireRole`, thread repo, and action repo:
    - All behaviors in `<behavior>` block
    - Assert `createAssistantAction` called for `propose_action` but no external job APIs invoked

    Export `executeApprovedToolCall` alias if needed by orchestrator (same module).
