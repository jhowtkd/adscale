## Locked decisions this plan implements

- D-01: Cliente > Campanha > Thread hierarchy — `campaignId` nullable on threads; `isDefault` for campaign default thread; `migratedFromThreadId` audit column.
- D-02: Message stream types `user | assistant | tool | action_card`; denormalized `workspaceId` on messages.
- D-03: Action lifecycle states `pending | confirmed | running | completed | failed | canceled`; `jobRefs` JSONB on action records.

## Schema discretion (per CONTEXT)

- Use `isDefault` boolean + partial unique index on `(workspace_id, campaign_id)` where `is_default = true AND campaign_id IS NOT NULL`.
- Thread-to-campaign migration uses FK update (`campaign_id` set) with `migrated_from_thread_id` — not a new thread copy.
</context>
