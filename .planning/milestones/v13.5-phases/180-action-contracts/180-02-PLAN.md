    - "quero reestilizar esse criativo" → `{ kind: "classified", intent: "quick_action", source: "heuristic" }`
    - "montar campanha completa para lançamento" → `{ kind: "classified", intent: "complete_campaign", source: "heuristic" }`
    - Message matching both quick and campaign keywords → `{ kind: "clarify", question: "Você quer uma ação pontual ou montar uma campanha completa?" }`
    - No action signal → `{ kind: "skip" }`
  </behavior>
  <action>
    Create `intent-classifier.ts` per RESEARCH Pattern 2 (ACT-01):

    Export `IntentClassificationResult` union:
    - `{ kind: "skip" }`
    - `{ kind: "classified"; intent: "quick_action" | "complete_campaign"; source: "heuristic" | "model_hint" }`
    - `{ kind: "clarify"; question: string }`

    Implement `classifyUserIntent(userMessage: string)` as pure function (no DB, no provider):

    - **Skip heuristic:** `^(oi|olá|ola|hello|hi|hey|bom dia|boa tarde)\b` case-insensitive AND trimmed length &lt; 40
    - **Quick keywords:** restyle, restyling, reestilizar, regenerar, pontual, quick, adaptar formato
    - **Campaign keywords:** campanha completa, nova campanha, lançar campanha, brief completo, estratégia de campanha
    - Both families match → clarify with exact Portuguese question from CONTEXT
    - Single family match → classified with `source: "heuristic"`
    - No match → skip

    Export `buildIntentPromptAugment(result: IntentClassificationResult): string | null`:
    - For `classified`: return block like `Intent family: quick_action — prefer contracts in that family when proposing actions.`
    - For `skip`: return fallback hint per RESEARCH Q3: "If the user requests an executable action and intent is unclear, ask one clarifying question: quick action vs. complete campaign."
    - For `clarify`: return null (orchestrator handles separately)

    Write `intent-classifier.test.ts` covering all behaviors above. Use discretion for exact keyword list — tests lock the chosen heuristics.

    Do NOT expose classifier as provider tool. Do NOT classify per actionType.
