<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → profile API | Untrusted JSON and file uploads from authenticated user |
| client → workspace settings API | Untrusted JSON; must not allow member to change workspace identity |
| avatar upload → R2 | Binary content; must validate type and size |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-171-01 | S | PATCH /api/user/profile | mitigate | Session required; reject email changes; zod max lengths |
| T-171-02 | T | PATCH /api/workspace/settings | mitigate | requireRole owner/admin on PATCH |
| T-171-03 | I | POST /api/user/profile/avatar | mitigate | Magic-byte validation + allowed MIME types (brand-kit pattern) |
| T-171-04 | D | PATCH workspace slug | mitigate | Rate limit via existing API middleware if present; DB unique constraint |
| T-171-05 | E | Profile GET | accept | User reads own row only; no elevation path |
</threat_model>
