    ```typescript
    export type RegenerationCorrectionBrief = {
      primaryReason: string;
      promptFeedback: string;
      structured: {
        parentDerivationId?: string;
        sources: Array<"hard_failures" | "score_issues" | "qa_failed" | "qa_warning" | "feedback_category">;
        hardFailures: Array<{ code: string; message: string }>;
        scoreIssues: string[];
    ```

    1. `contract: CreativeContract` (required)
    2. `hardFailures` (default [])
    3. `scoreIssues` (default [])
    4. `qaChecklist` (Record of criterion → { status, note }) — extract `failed` as blocking, `warning` capped at 3 for prompt (all failed + up to 3 warnings in primaryReason)

    7. `parentDerivationId?: string`

    Import taxonomy display helpers from `creative-quality-taxonomy.ts` for criterion IDs in QA sections (map unknown keys to raw key).

    `promptFeedback` assembly order: issue sections → optional model suggestion line → preservation tail via `buildRegenerationSuggestion({ contract, scoreIssues: [], modelSuggestion, ctaText/format/generationMode from contract })`.

  Implement `mergeUserRegenerationNotes(machineBrief: string, userText?: string): string` per D-02 default (AIR-02): if trimmed user text empty → machine brief; if user text equals machine brief (normalize whitespace) → machine brief; else append `\n\nAdditional notes: ${userText}` after machine brief (do NOT replace blocking sections).
