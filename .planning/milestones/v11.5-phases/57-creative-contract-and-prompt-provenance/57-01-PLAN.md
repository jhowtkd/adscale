    Required behavior:
    - Resolve `sourcePackage` before prompt building:

      - `campaign_asset` otherwise.
    - Resolve source descriptor:

      - parent derivation id/outputKey when using an approved derivation.

    - Build `promptProvenance` before generation with `inputPrompt`, model, requested size, target format, mode, source package, and source descriptor.
    - Update `promptProvenance` after OpenAI returns with revised prompt, operation type (`edit`, `generation_fallback`, or `generate`), and output key.
    - Continue passing the same `contract` object to prompt builder, scoring, and quality gate.
