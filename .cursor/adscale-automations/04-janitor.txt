NAME:
Janitor - Safe Code Cleanup

DESCRIPTION:
Weekly safe code cleanup for ADScale. ONE low-risk maintainability improvement with no behavior change.

SCHEDULE (cron):
0 13 * * 2
(Terça ~10:00 BRT)

REPOSITORY:
jhowtkd/adscale

BRANCH:
main

INSTRUCTIONS:
Global rules for this automation (ADScale / jhowtkd/adscale):

Work in the smallest safe scope possible.
Improve exactly ONE meaningful thing per run.
Do not mix unrelated concerns.
Do not make broad refactors.
Do not introduce new dependencies unless explicitly allowed.
Do not modify package.json, lockfiles, tsconfig, CI/CD, database schema, authentication, authorization, billing, or public API contracts unless this automation specifically allows it.
Prefer existing project patterns over new abstractions.
If there is no valuable opportunity, stop and report "No action taken".
Never claim tests, lint, typecheck, or build passed unless the command was actually run.
If a command cannot run, report the exact reason.
Open a PR only when the change is safe, focused, and verified.

ADScale-specific:
- Application code lives in app/ — run all npm scripts from app/.
- API routes: app/src/app/api/
- Server/domain logic: app/src/server/
- UI: app/src/components/ and app/src/app/
- i18n: next-intl via app/messages/en.json and app/messages/pt-BR.json (update BOTH when adding keys)
- Tests: Vitest (config/vitest.config.ts); vi.hoisted + vi.mock for Drizzle
- Fixtures: tests/fixtures/, *.fixture.ts (no MSW, no Storybook, no faker)
- Analytics: @/server/beta-analytics; errors via Sentry — never PII
- Critical domains: campaigns, derivations, quality gates, credits/Stripe 402, workspaces, Better Auth, Inngest jobs, R2 assets
- Docs: README.md, app/README.md, docs/adr/

Mission: Clean up ONE low-risk technical debt that clearly improves maintainability.

Scope: unused imports, dead local code, stale comments, tiny duplicated utilities, unnecessary nesting, unreachable branches in app/src/.

Allowed: remove unused imports; remove unreferenced local functions; delete stale comments; early-return simplification; obvious existing constants.
Forbidden: remove dependencies; delete code referenced by Inngest, dynamic routes, config strings, migrations; large refactors; behavior changes; touch public APIs/DB without tests.
Stop if: weak dead-code evidence; >5 files; behavior might change; no verification path.

Verification:
cd app && npm test
cd app && npm run lint
cd app && npm run typecheck
cd app && npm run build

Output: 1) Opportunity 2) Safety evidence 3) Files 4) Behavior impact 5) Verification 6) Left untouched
